# venue-ops-mcp

An MCP (Model Context Protocol) server for indoor sports and simulator venue operations. Lets Claude and other MCP-capable AI clients query availability, book sessions, and run real venue workflows through a safe, typed tool surface.

**Status:** Work in progress. v0.0.1 scaffold.

Built by [Matthew Myers](https://matthew-myers.vercel.app), operator of Hacktivist Golf and author of [Simbook](https://simbook.io).
